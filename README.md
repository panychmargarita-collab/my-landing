ViaGo — Travel Agency Website

ViaGo — це сайт туристичної агенції, який допомагає користувачам ознайомитися з популярними напрямками для подорожей, дізнатися про переваги агенції та вибрати відпочинок.

 Використані мови:
- HTML
- CSS
- JavaScript

JavaScript функції:
- Відкриття та закриття бургер-меню.
- Гортання карток у слайдерах.
- Інтерактивна взаємодія з елементами сайту.
